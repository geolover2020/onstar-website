# توسعة الشروحات — موقع OnStar

## ما الذي أُضيف؟

تم توسيع صفحة `/tutorials` بإضافة تبويب «شروحات لوحة الأجهزة» يحتوي على 36 شرحًا عربيًا منظمًا في 7 أقسام، مع 182 خطوة استعمال وملاحظات عن الصلاحيات والأمان. الشروحات نصية مقروءة مباشرة داخل الموقع؛ **ليست فيديوهات جديدة**.

تبويب «شروحات الفيديو» يحتفظ بروابط مقاطع YouTube الـ35 الموجودة أصلًا دون تعديل.

## استخدام القسم

- افتح «الشروحات» من قائمة الموقع.
- اختر «شروحات لوحة الأجهزة» أو «شروحات الفيديو».
- اكتب اسم الميزة في البحث أو اختر أحد الأقسام.
- اضغط بطاقة الشرح لفتح خطوات مفصلة، مع ملاحظات السلامة.
- يمكنك مشاركة رابط شرح محدد بعنوان من نمط `/tutorials?guide=...`.

## حدود التعديل

ملفات معدلة:
- `src/pages/Tutorials.jsx`
- `src/components/Header.jsx` (تحديث وصف الشروحات فقط)

ملفات جديدة:
- `src/data/platformGuides.js`
- `src/styles/platform-tutorials.css`
- `README_TUTORIALS_RELEASE_AR.md`

لا تغييرات على: نظام الحسابات، الصفحات الأخرى، `studio-data/site_content.json`، التطبيق، الخادم، مفاتيح الوصول أو واجهات API. بيانات الأدلة مخصصة للنشر العام ولا تتضمن عناوين خوادم أو كلمات مرور أو أوامر إعداد.

## التطوير والنشر

عند توفر الإنترنت على بيئة البناء: `npm ci && npm run build`، ثم نشر مجلد `dist` أو ربط المشروع بنظام النشر المعتاد. لا ترفع `node_modules` إلى المستودع.

> قد تختلف مسميات الأزرار وبعض الأدوات بحسب الإصدار والصلاحيات المتاحة للحساب. راجع الشروحات إذا تغيرت أسماء الوظائف في الإنتاج.
