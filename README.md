# OnStar Website

موقع OnStar الرسمي — الإصدار الثالث.

## التشغيل محليًا

```bash
npm install
npm run dev
```

## بناء نسخة الإنتاج

```bash
npm run build
```

## Netlify

- Build command: `npm run build`
- Publish directory: `dist`

ملف `netlify.toml` موجود مسبقًا ويدعم SPA redirects.
